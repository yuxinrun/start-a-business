# 创业书单：哪些值得读完

周六下午，你在一个"创业必读五十本"的清单里往下滑，滑到底只记住了前三本书名，收藏完就又去刷手机了。

那种清单是给转发量写的，不是给你写的。它把"验证想法"的书和"带五十人"的书混在同一个榜上，好像阅读顺序不重要。

这页换个排法：按你现在卡在哪一步排。十二张书卡已经列在下面了，每张比常见书架多写一栏——"读完容易被读歪成什么"。正文只负责三件事：先读哪本、哪本只读一章、以及怎么读才不会白读。

## 十二本分三档，先补最前面那档

先把顺序说清楚，因为下面这块卡片在听书时会被整段跳过。前五本管"到底有没有人愿意付钱"，中间六本管"卖得动了、也交接得出去"，最后一本留到你真要带人的那天再读。

如果还在验证，别跳序。第一本是《The Mom Test》，它薄，一两个晚上能读完，专治"问了一圈亲戚都说挺好"。

已经开张有流水了，直接翻到"卖得动"那一档。还在纠结要不要辞职、要不要找人投的，后面几档暂时用不上。

这三档不是评分，是顺序。跳着读最常见的后果，是拿一本讲组织的书去解决"根本没人买"的问题。

上面这块就是那十二张卡。它按阶段排、不按好坏排，卡片里已经写好了每本的难度、时长和误读风险，正文不再重复。

## 有本书只值其中一章，别从头啃到尾

不是每本都配得上你逐页读完。有的整本都值得，有的只值一个动作。

《Traction》最值钱的是 Bullseye 那套填表流程，后面列的渠道当词典查就行——那是 2015 年美国的渠道快照，微信、抖音、小红书一条都没有。

《商战》是给已经有产品、却还是卖不动的人准备的。你还在验证、连可占据的心智都没有，整本可以先跳过。

《创新者的窘境》值得读两遍：第一遍跟着那些在位者失败的历史走一遍，第二遍只挑对首创业者有用的那条——去服务被主动放弃的客户。

本站允许说一句"这本最值钱的是某一章"。把工具书当小说从头读到尾，是这十二本共同的浪费。

## 读完不等于会做

书给你一套说法，账本要的是一个动作。把一张画布填完不等于验证过了，读完一遍也不等于会问客户。

<div class="mp-quote">挑一条做掉，比再买一本有用。</div>

这也是每张卡都逼作者给"今晚就能做完的动作"的原因：给不出动作的书，本站没有给它推荐位。

## 读创业书，先问三件事

先分清主张和事实。"用精益方法的公司存活率更高"这句话，书里从来没量化过，撑它的基本是作者自家公司的自述。

再看案例能不能当证据。有研究统计了三本经典书里的五十家公司，五年后只剩五家维持原来的水平——从赢家身上倒推出来的特质，常常经不起追踪。

最后追数字的口径：样本是谁、分母是什么、哪一年抓的。这也是每张卡都标证据等级的原因。
