# 这本手册怎么用（先做 3 分钟自评）

你手上大概有三件事同时没做完：一个还没验证过的想法、一笔说不清能不能亏的钱、一份还没辞的工作。这时候最没用的建议是"先想清楚商业模式"。

所以这本手册不按"知识体系"排，按**你会在哪一步卡住**排。三十八页正文，每页只回答一个问题，第一屏就给答案。

## 先花三分钟，知道自己卡在哪一格

自评把问题拆成四格：**准备**（钱和心理缓冲够不够）、**赛道**（这件事能不能算清一单）、**算账**（毛利、现金流、回本）、**组织**（人、股权、分工）。

  <div class="mp-stat"><strong>0–20</strong><span>分数越高，那一格越拖后腿</span></div>

这四格不会被念出来，所以用完整的话说一遍：自评一共十道题，覆盖四格，每题零到两分，满分二十分，分数越高说明那一格越拖后腿；答案存在你自己的浏览器里，不上传任何地方，随时可以清空重做。

## 三条入口，别从第一章开始读

<RoadmapStrip />

上面这条时间线里值得记住的是中间两段：**活过第一年**和**一单的账算平**。绝大多数散伙发生在这两格之间，而不是发生在"没想清楚商业模式"的时候。

- **还没辞职**：读 [你适不适合创业](/ready/self) → [启动资金：亏多少会伤到你](/ready/money) → [第一年真实的账](/ready/first-year)。这三页不谈理想，只谈缓冲垫有多厚。
- **已经辞职、正在选做什么**：读 [选行业的三步](/industry/how-to-choose) → [行业菜单](/industry/menus) → [红海、蓝海与「看起来很赚钱」](/industry/red-ocean)。
- **已经在做，但说不清赚不赚钱**：直接跳到 [一单的账](/model/unit-economics) → [现金流](/model/cashflow) → [看哪几个数](/run/metrics)。这一条路的人通常最快有反应，因为账是能算的。
