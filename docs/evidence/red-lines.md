# 我们不写的说法：本站拒绝印的清单

群里有人转了条短视频，标题是"九成创业公司第一年会死"，底下一排"还好没辞职"。你要反驳，却说不出那句到底哪来的。

这页就是拿来补这一口的。它不给你新数字，它列出本站拒绝印的东西：查不到出处的口号、两个口径混起来会害人的数、我们明确不给的具体数字，还有整一类我们根本不碰的内容。

每条都写成三段：你想问什么、为什么本站不给、能给读者的又是什么。下面的行号都能在事实库里逐条回查。

## 查不到出处的口号，本站不当事实印

这几格听不到，所以用完整句子再说一遍。那句流传最广的"九成创业公司会死"，这一轮查不到任何一手统计来源。常被拿来给它撑腰的那组数，分母是"还在报工资的企业"，压根没数一个人的公司——错配的是分母，不是算术。

能核的口径是这样：美国新增雇主企业第一年约八成还在报工资，第五年约一半还在。这里数的是"还在报工资"，不等于"还在赚钱"。至于"中国创业成功率是多少"，官方统计里没有这个指标，能查到的只有新设量、在册存量、注销与吊销数量，它们都不等于失败率。

| 流传说法 | 为什么不给 | 本站改写成什么 |
|---|---|---|
| 多数创业公司第一年会死 | 查不到一手出处，撑腰数据分母错配 | 第一年约八成还在报工资、第五年约一半（BLS 口径，不等于赚钱） |
| 一半的初创活不过第一年 | 把五年那道门槛搬到了第一年 | 死亡率集中在头一两年，"一半"是第五年的数 |
| 餐馆小店九成两年内死掉 | 行业存活表不支持这句话 | 餐饮十年存活约四成上下、两年约七成，且是幸存者口径 |
| 中国企业平均寿命几年 | 查不到官方一手出处 | 只给能核的幸存者比例，不写"平均寿命" |
| 中国创业成功率是多少 | 官方统计里没有这个指标 | 只给新设、在册、注销与吊销数，并写明"注销≠倒闭" |

## 口径混起来会害人的数，本站拆开摆

同一件事往往有两套数，各自都不算错，合并成一个才开始害人。本站的做法是分开摆，绝不取平均。

"平台到底抽多少"最常见：公示的是技术服务费，商家真正扛的是它加上履约、配送、被分摊的补贴成本。这两个数差着一截，补贴那部分多由商家承担、还常常不计入佣金。

| 你想问的 | 为什么不能并成一个数 | 本站怎么处理 |
|---|---|---|
| 平台总共抽我多少 | 公示费率与综合负担是两个口径 | 两栏分开摆，写明"公示费率≠商家总成本" |
| 开店能有多少净利率 | 年报是集团口径，含加盟费与总部议价 | 净利率分布 0.9%–16.6% 只当行业分布看，年报不是你的预算表 |
| 加盟是不是比自营更容易活 | 流传的对比数方向存疑、疑转述错位 | 不写"加盟更安全/更危险"，先当营销话术看待 |

同一行里，净利率从 0.9% 到 16.6% 都摆得下：这是分布，不是谁特别会经营。所以别人的年报不是你的预算表。

## 这些具体数，我们直接拒印

有几类数不是"暂时没查到"，是压根没有可靠一手，或者给了就会变成承诺。本站一律不印具体数字，改成算法或一个你能自己做的查询动作。

| 想问什么 | 为什么不给具体数 | 本站改写成什么 |
|---|---|---|
| 境内创始人融资后还剩多少股 | 没有公开统计，境外样本只覆盖拿风投的公司 | 只讲规则与稀释算例，绝不写"国内创始人平均持股 X%" |
| 个体户每月到手能挣多少 | 官方未公布经营净收入分布 | 给算法：营收×净利率区间，再扣掉你自己的五险 |
| 银发经济有多大 | 口径含糊、机构估计差数倍 | 只留国办文件的四大方向与举措，规模数字不引 |
| 开一家店几个月回本 | 统计局、商务部、行业协会都查不到平均回本周期 | 给回本月数算法（本站算法，不是结论），不给月数 |
| 一次性创业补贴给多少 | 全是县市级文件，没有全国标准 | 给查询路径：当地人社局、政务服务网政策清单 |

回本那条值得单独说：你听到的每一句"几个月回本"，来源要么是品牌方的招商材料，要么是自媒体转抄。本站不接这个话头，只教你怎么自己算垫付和现金。

## 这几类内容，本站整类不碰

下面这些不是"要带限定语"，是根本不做。出现任何具体品牌，只可能是举例某类做法，绝不代表推荐。

这四类的共同点是一句话：本站只摆口径，不替读者背书，也不替读者算账。

涉及税、社保、公司法的每一段，本站只讲法条能确认的门槛与后果，再补一句"具体架构请找执业律师、会计师、当地人社局"。
