# 持股比例不是控制权，表决权才是

融资谈完，你手上还剩 51%。你一直以为过半就是说了算，直到有人提醒：公司章程里那句"表决权不按出资比例"，是你三年前自己签的字。

这句话是本页最值钱的一句——"持股比例"和"表决权"是两件事。有限公司里，章程或者全体股东的约定，可以让表决权、分红比例都不跟着出资比例走（境内"AB 股"最日常的形态正是这个，不是上市那套；条文号以现行《公司法》原文为准）。

## 四条线记成一句话，但它们是口诀不是法条

创业圈流传四条线："67% 绝对控股、51% 过半、别低于三分之一、别让人低于 30%"。这是律所和投资人的经验法则，属 C 级——没有任何一手研究验证过这些阈值，只能当操作清单，不能当研究结论。

把它们放回能查到的口径：一般理解里，特别决议要三分之二以上表决权才过得去，改章程、增减注册资本、合并、分立、解散、变更公司形式都算这一档；除特别决议以外的事项走"过半数"，选董事、审报告、日常经营落在这一档。具体哪些事项、基数按全体还是按出席会议的表决权算，以现行《公司法》、登记机关口径和你的章程为准，本页不断言逐条列举。

上面这三档里，最容易被抄错的是 30%。还要注意：这类"绝对控股"讲的是中国公司法的治理，别硬套到美国 Delaware C-corp。

## 真想把方向握住，多数公司走的是事先写清楚

比比例更管用的，是把"谁来投票"提前落到白纸。境内实践里能查到的一家是优刻得——科创板首家设表决权差异安排的公司，A 类每股 5 票，再配一份《一致行动协议》。注意措辞：是"首家"，不是"常见"。

一致行动、表决权委托在有限公司阶段主要靠协议本身，法律并未禁止；上市或挂牌后的一致行动，才另须按规定披露。所以协议里要写清违约条款与终止条款——它是合同安排，不是法定特权。本页不给条款模板、不给具体数字。

## 别把 AB 股当退路，它第一道槛是体量

非上市有限公司靠章程另约定表决权就够了，用不着 AB 股。真到上市层面，"同股不同权"的门槛很高：按上交所科创板口径，预计市值不低于 100 亿元，或者不低于 50 亿元且最近一年营收不低于 5 亿元。

上面这四张卡连成一句：AB 股不是想用就能用，而且是一次性的时点决定。一人公司在设立那天定的章程，比事后补救重要得多。

顺带辟一条谣：有个常被引用的故事说乔布斯在苹果 IPO 后持股被稀释到约 15%、后来被董事会赶出去。这是流传叙事，没取到当年招股书原文，那个百分比不能当事实引用。
