# 关于本站

<BrandMark variant="card" />

这本手册由「鱼心快跑」写。母品牌有一条小鱼，每个站点按自己的主题给它换姿势：讲睡眠那站它戴睡帽抱枕头，这一站它戴着安全帽，推一枚比自己还大的飞轮。

选飞轮而不是火箭做吉祥物，是因为这本手册全程在讲前者，而大多数人脑子里的创业是后者。

这四格不会被念出来，所以用完整的话说一遍：底稿一共四份，国际证据一百一十八条带链接的事实行，中国口径一百七十四条，实操账本一百七十三条，书单覆盖二十二本书、十二组矛盾对照。

然后汇总成一份分级事实库，正文里出现的每个数字都必须能在里面找到出处。等级只有三档：

- **A 可核**：直接在机构页面、论文全文或一手报告里读到那个数字。可以直接写。
- **B 需限定**：结论成立，但必须带着样本、设计或因果性的限定语一起写。限定语进正文，不进脚注——因为听书的人读不到脚注。
- **C 流行**：广泛流传但找不到一手出处。这类只允许出现在辟谣那一章，并且第一句就写清楚"这是流传说法"。

## 结论互相打架时怎么办

**不平均。** 两个来源给出的数不一样，通常是因为分母不一样，把它们平均出来的那个新数字没有任何人能负责。

所以站内的做法是并列摆：投资人说跑道要留十八个月，同时写清那是筛项目的经验线；美国劳工统计局说新雇主企业第一年后约八成还在，同时写清那数的是"还在报工资"、而且分母不含一个人的公司。

最典型的一处冲突是关于股权平分。流传说法是"五五分必翻车"，而目前最大的公开股权数据集（Carta，覆盖三万两千家以上公司）显示两家平分股权的占比其实在上升，从 2015 年的 31.5% 涨到 2024 年的 45.9%，一线孵化器也推荐接近平分。这两件事同时成立，所以 [股权分配那一页](/structure/equity) 不给你选边，只把"平分"和"没有兑现机制"拆开讲。

## 我们拒绝印的东西

有一批数字我们查到了转述，但查不到一手出处，于是决定不印：各类"创业成功率""企业平均寿命""平台商家存活率"，"八成的公司死于现金流"，加盟费的真实构成，各行业复购与 NPS 基准，各省社保费率的具体表。它们出现在 [红线清单](/evidence/red-lines) 上，写清楚为什么不上正文。

同样不上正文的：避税方案、规避劳动法的做法、代持与阴阳合同的操作细节、融资谈判话术、把数据包装得好看的技巧、任何具体项目或基金或平台的推荐。
