# start-a-business 组件契约（图表 / 交互件）

这份文件是三方的共同合同：写组件的人照它画，写正文的人照它在页面里插标签，最后核对的人照它查数字。
**组件里的数据是"待核草稿"**：数值取自通行口径，事实库（`.qoder/factbase.md`）到位后统一校对一次。

## 一、文件与结构约定

- 路径：`docs/.vitepress/theme/components/<PascalCaseName>.vue`
- 全部**数据内嵌**（`const XXX = [...]` 放在 `<script setup lang="ts">` 顶部），组件**不接受必填 props**；可选 `variant` 只用于同一组件的两种排布。
- 组件目录里新增的 `.vue` 会被 `theme/index.ts` 自动注册，不用改注册表；markdown 直接写 `<ComponentName />`。
- 根节点固定：

```html
<div class="sb-<kebab-name> sb-widget" data-listen="skip">
  <div class="sb-widget-head">
    <span class="sb-widget-title">English Label · 中文标签</span>
    <p class="sb-widget-sub">一句话说明这张图在回答什么问题（口语，可带一点幽默）</p>
  </div>

  <!-- 图形本体 -->

  <p class="sb-cap">结论句：**关键数字用 `<b>` 包住**，一句话说清"所以呢"。</p>
</div>
```

- `data-listen="skip"` 是**硬性要求**：听书引擎靠它跳过图形，避免把坐标轴数字念成一串乱码。信息必须写在 `sb-cap` 里，否则听客拿不到。
- 共享类（已在 `style.css` 定义，不要重复实现）：`.sb-widget` `.sb-widget--dash` `.sb-widget-head` `.sb-widget-title` `.sb-widget-sub` `.sb-cap` `.sr-only`。
- 私有类一律 `sb-<kebab-name>-xxx`，写在 `<style scoped>` 里。

## 二、只能用这些 token（不许出现新颜色）

```
底色   --bg --bg-soft --panel --panel-2 --panel-3
文字   --ink --ink-2 --muted --faint
描边   --line --line-strong
语义   --accent(teal 主/正常) --coral(风险/警示) --blue(信息/第三系列) --lime(第四系列)
       --accent-soft --coral-soft --blue-soft
排版   --font-sans --font-mono --radius-sm(10) --radius(18) --radius-lg(28) --ease --shadow
```

- 三系列固定语义：**teal = 健康/推荐/自己出钱/正常经营**，**coral = 风险/坑/现金缺口/红线**，**blue = 中性第三项（如外部资金、对照组）**，lime 只在需要第四分类时用。
- 钱相关的图统一约定：**流入用 teal，流出用 coral，账期缺口用 coral 虚线**。不要为了好看换色。
- 需要半透明时用品牌色的 rgba（`rgba(10,149,138,.12)` 浅 / `rgba(53,216,196,.14)` 深，配 `html.dark` 覆盖），不要引入新 hue。
- 元信息（轴标签、图例、单位、编号）一律 `font-family: var(--font-mono)` + 9–11px + `letter-spacing: .06em~.14em` + 颜色 `--faint`。正文用 sans。
- 质感三件套：点阵（`.sb-widget` 已自带，别重复加）、虚线（`1px dashed var(--line-strong)`）、大扩散阴影（`--shadow`）。
- **百分比条形必须落在专门的轨道里**：外层用 `display:grid; grid-template-columns: minmax(0,1fr) 58px`，把条放进第一列的 `.sb-xxx-track { min-width:0 }`，数值标签放第二列。直接把 `width:xx%` 塞进含标签的 flex 行会在窄屏溢出（上一个站真实踩过）。
- **SVG 数据点必须落在 viewBox 内**：先算好末端坐标再写映射函数，被裁掉的曲线算不出来、只看代码看不出来。

## 三、SSR / hydration 红线（违反会让全站每页报错）

1. 组件在 `setup` 阶段**不许碰** `window` / `document` / `localStorage` / `matchMedia`。
2. 不许 `Math.random()`、`Date.now()`、`new Date()` 参与渲染结果。
3. 交互件的初始状态必须在服务端和客户端**完全一致**（例如自评问卷初始 `answers = null` 数组，而不是从 localStorage 恢复后再渲染）。要恢复用户数据，用 `const mounted = ref(false)` + `onMounted` 里置 true + `v-if="mounted"` 包住依赖本地存储的部分（参考 `ListenBar.vue`）。
4. 块级元素不能塞进 `<p>`（浏览器会自动断段，直接造成 mismatch）。`sb-cap` 里只放行内元素。
5. 装饰性 SVG 加 `aria-hidden="true"`；承载信息的图给 `<figure>`+`<figcaption>` 或 `.sr-only` 文本。
6. `prefers-reduced-motion: reduce` 下动画自动失效（用 `transition` 而不是 `animation` 循环；必须循环的转动点在 media query 里关掉）。

## 四、响应式

- 桌面双栏/横轴的图，`@media (max-width: 760px)` 必须转成单栏或纵轴；窄屏是另一套读法，不是等比缩小。
- SVG 用 `viewBox` + `width:100%; height:auto`，不要写死像素宽高。
- 表格型组件在 ≤760px 允许 `display:block; overflow-x:auto; white-space:nowrap`。
- **交付前自测 360px**：把组件放进 360px 宽容器，`scrollWidth - clientWidth` 必须为 0。

## 六、各组件的数据草稿

> 单位、口径写进 `sb-cap` 或图注。凡是"待核"的，事实库到位后改一次。所有人民币数字一律写成"约 X 万元"，美元写"约 X 万美元（≈X 万元）"，不混用。

### RoadmapStrip
五段：想法与验证 → 开张（主体+首单）→ 活过第一年 → 单位经济算平 → 可复制（团队/流程）→ 规模化。每段配"最常见的死法"一句话。危险段（第一年、算平）用 coral 描边。

### FounderFitRadar
六维：现金流承受力 / 行业手感 / 能卖得出去 / 忍得了无聊 / 会用人 / 能承认错误。示例两个轮廓：`准备度 A（已在这行 5 年、家里有缓冲）` vs `准备度 B（技术强、没销售过、只有 6 个月存款）`。要点：**雷达不是算命**，它只是把"你缺的那一角"说出口；缺角可以用合伙人补，不可以用"我很努力"补。

### RunwayBucket
输入三档：`all-in 辞职做` / `下班做副业` / `拿别人的钱做`。横轴月燃烧率（1 万 / 3 万 / 8 万 每月），纵轴可撑月数 = 可亏资金 ÷ 燃烧率。标注"18 个月"这条经验线（待核：这是投资人口径，不是生存口径）。要点：能亏的钱要单独算，**不要把房租和孩子的学费算进启动资金**。

### FirstYearCurve
12 个月现金余额折线。示意：前 3 月负斜率最陡（装修、备货、注册、社保一次性支出），第 5–6 月出现谷底（待核），第 9 月起转正。谷底标注"这里最容易做错误决定：借钱续命 or 收缩"。口径强调：**这是现金余额，不是利润**，两个数可以符号相反。

### ExitClauseCards
4 张：① 分手价怎么定（估值方法，不是"谁嗓门大"）；② 谁有权让谁走（回购权与触发条件）；③ 竞业与 clientela（不能再做同一件事多久）；④ 债务与担保谁背（个人担保不随散伙消失）。每张写"没写这条的真实代价"。红线：不写具体金额条款模板，只给结构；提示"这四条要在开工前找律师落成书面"。

### IndustryFunnel
第 1 层：100 个想法 → 剩 20（能算清一单账的）；第 2 层：20 → 5（你能接触到客户的）；第 3 层：5 → 1（亏得起 + 一年后还在的）。宽度按数量比例。每层写淘汰理由，不是"运气"。

### SectorLedger
5 类对照（草稿，待核）：餐饮门店 / 社区服务（维修、保洁） / 电商零售 / 企业服务外包 / 内容与知识付费。四项指标：首单毛利率、复购周期、启动资金量级、回本周期。用分组条对比，同一指标内归一化到 0–100%，**真实数值写在 `.sr-only` 与正文里**，别让读者从归一化条猜绝对值。

### RedOceanMatrix
横轴：竞争密度（低→高）；纵轴：需求增速（低→高）。5–6 个点（社区养老照护、宠物医疗、职业技能培训、奶茶加盟、跨境电商 3C、企业 SaaS 分销）。四象限命名：高增长+高竞争 = "值得进但要有刀"；低增长+低竞争 = "小生意，稳但别融钱"。要点：**红海不是不能进，是不能空手进**。

### EntryLadder
三级：副业试水（风险低/可控度中/上限低）→ 加盟（风险中/可控度低/合同决定一切）→ 自创品牌（风险高/可控度高/最慢）。每级写一句"什么时候选它"。加盟必须写清：加盟费只是开始，真实成本在物料强制采购与区域保护条款（待核）。

### UnitEconomicsStack
一杯咖啡 / 一单电商 / 一次上门服务三种样例，同一种画法：售价 → 直接成本（原料/货+包装+履约）→ 获客分摊 → 贡献毛利。贡献毛利为负的用 coral。结论句：**贡献毛利为负时，卖得越多亏得越多，规模救不了单位经济**。

### PricingLadder
三档：低价冲量 / 中间常规 / 高价窄众。每档给 单价、预计月单量、月毛利、库存与售后压力。要点：定价改的是"谁来买 + 你有多少事要做"，不是单纯改数字；降价是花真金白银买转化率（毛利损失即时、销量提升滞后）。

### CashFlowGap
横轴月份，两条线：付款（上游/工资，teal 支出）与收款（客户回款，coral 缺口）。中间填色 = 需要的周转资金峰值。示例：账期 60 天、月结工资，峰值缺口约 2 个月的支出（待核）。结论句：**"利润是观点，现金是事实"——赚钱的公司在等回款的那 60 天里也能死掉**。

### MarginWaterfall
收入 100 → 毛利（扣直接成本）→ 扣房租人力 → 扣营销 → 扣税费与管理 → 净利。下方一条行业参考带（餐饮 / 零售 / 服务 / SaaS 的常见净利区间，待核）。要点：**"毛利率 70%"不等于"赚 70%"**，很多人把两个数当一个。

### FundDecisionTree
4 个岔口：① 这件事需要外部钱吗（有规模效应/网络效应？）；② 你能接受稀释到多少；③ 现在有没有可验证的增长数据；④ 拿钱附带的条件你履行得了吗。叶子给出三类结论：不建议融资 / 用自有资金+贷款 / 可以见投资人。红线：不承诺融资成功率，不教做假账式包装。

### RoundDilution
轮次：自有资金 → 天使 → Pre-A/A → B → C。每轮典型出让 10–20%（待核），累计到 C 轮后创始团队持股示意 20–35%（待核）。柱子=本轮出让，折线=创始人剩余持股。要点：**稀释本身不是坏事，用便宜的钱换不该你做的事才是目的**；同时标出"每轮的代价不只是百分比，还有条款"。

### TermSheetAnatomy
6 条：估值（pre/post）、清算优先权（1× non-participating vs participating）、反稀释、董事会席位、对赌/回购、解锁与竞业。每条三行：这条讲什么 → 怎么咬人 → 常见区间（待核）。红线：**不给出"谈判话术"、不承诺可谈到什么条件**，只教读者"这三条要花钱请律师读"。

### FundSourcesCn
来源占比条：自有资金 / 亲友 / 银行贷款与政策性担保 / 政府补贴与园区扶持 / 天使与机构（待核口径，用"绝大多数新公司一辈子拿不到机构投资"这类不印具体百分比的表述）。本土规则清单：注册资本认缴与实缴期限、股东出资责任、对赌与回购的司法态度、地方产业基金返投要求（待核）。红线：不预测政策变化、不给避税方案。

### EntityCompare
四列：个体工商户 / 个人独资企业 / 合伙企业（普通合伙、有限合伙） / 有限责任公司。四行：责任边界、税（经营所得 vs 企业所得税+分红个税）、能不能发股权融资、适合谁。要点：**"要不要有限公司"取决于你是否要发股票、是否要雇人、是否有对外责任**，不是"听起来正式"。

### VestingCurve
4 年按月兑现 + 1 年 cliff 示意；两条线：正常在职兑现 vs 第 1 年内离开（拿 0）。标注：兑现不等于已到手，离职时的回购价条款才是重点（待核具体条款惯例）。结论句：**"先干活后拿股"保护的是留下来的人**，包括保护刚被给股的那个人自己。

### ControlThreshold
刻度轴：30% / 34% / 51% / 67%（中国公司法口径，待核：哪些事项需三分之二以上表决权）。每个刻度写"到这条线你能/不能决定什么"。要点：**控制权靠章程与协议，不只靠比例**；一致行动、投票委托、AB 股是另外三条路。红线：不写"如何绕开法律"。

### OrgStages
三阶段：10 人（一人多岗，创始人是首席销售）→ 50 人（职能分组 + 中层出现，信息开始失真）→ 150 人（事业部/业务线，靠流程与例会而非喊话）。每阶段写"这个阶段最典型的错误"：10 人错误是过早设部门；50 人错误是还用"我说过了"当沟通机制；150 人错误是没有 SOP。

### HireOrder
时间线：第 1 个能自己交付的人 → 第 2 个带来客户的人 → 第 3 个把流程写下来的人 → 之后才是行政/财务共享。渠道效率条（待核口径）：熟人推荐 / 垂直社区 / 招聘平台 / 猎头，各按"质量 × 速度 × 成本"三点评分。红线：不承诺招聘时效、不写"背调可以查什么"的越界做法。

### PayCostBreakdown
示例：月薪 10,000 元的真实用人成本堆叠条 = 到手 + 五险一金（企业部分）+ 商业福利 + 工位设备 + 招聘与管理的隐性成本。用可切换的三城示意（一线/二线/三线费率不同，待核）。结论句：**"给 1 万"和"每月这个人花 1.4 万"都是真话，做预算要用后者**。红线：费率每年变，页面必须写清"以当地当年口径为准，这里是示意"。

### LaborRedLines
6 条红线卡：试用期长度与次数上限、试用期工资下限、不缴社保的"自愿放弃"协议无效、加班与举证、无过失辞退的 N/N+1 与违法解除的 2N（待核口径）、竞业限制补偿与范围。每条：常见做法 → 为什么违法 → 正确做法。红线：**不教规避劳动法**；页面显著提示"个案咨询当地人社局 12333 或专业律师"。

### CacPayback
三栏：CAC（获客成本）/ LTV（客户终身价值）/ 回收期（月）。判断线示意：LTV ÷ CAC ≥ 3、回收期 ≤ 12 个月（标注为投资人常用经验线，不是经营铁律，待核）。加一条渠道饱和曲线：同一渠道投放翻倍、获客只增 40–60%（待核）。结论句：**先算清回收期，再决定要不要加预算**。

### FlywheelDiagram
5 个节点闭环：更好的交付 → 更多老客户 → 更低的获客成本 → 更多可投回的钱 → 更好的交付。中心写"你真正在推的是哪一环"。另标 2 个"打断点"：交付质量下滑、现金断供。红线：**不承诺飞轮会自动转**，图上要写清每一环都需要人推。
